# LOTM UI Diagnostics Tool

Автономный инструмент диагностики интерфейса и шрифтового движка для игры **Lord of the Mysteries** (C7, Unreal Engine 4 / LuaJIT).

Инструмент позволяет в один клик установить диагностический модуль в игру, автоматически собрать исчерпывающий отчёт о состоянии шрифтов, виджетов (UMG/Slate) и логов движка, выявив причины растягивания или некорректного отображения текста.

---

## 🎯 Возможности

- 🚀 **100% Автономность**: установщик не требует сторонних библиотек, распаковки архивов или ручного перемещения файлов.
- 🔍 **Глубокий инспектор виджетов**:
  - `Font.FontObject` (название ассета шрифта, fallback/composite font)
  - `Font.LetterSpacing` и `widget.LetterSpacing`
  - `Font.Size` и `DesiredSize` (геометрия Slate)
  - Полное иерархическое дерево родительских виджетов (`ParentPath`)
  - Текстовое содержимое виджета
- 📊 **Мониторинг панелей**: перехват хуков `UIComponent.Open`, `UIComponent.Refresh` и периодическое сканирование активных панелей UI.
- 📝 **Комплексный сбор логов**:
  - Чтение `lotm_diagnostics.json` и `lotm_diagnostics.txt` из `<Game>/Saved/Logs/`
  - Сканирование `C7.log` на наличие предупреждений шрифтового движка (`LogSlate`, `LetterSpacing`, `Glyph`, `FontCache`, `FreeType`)
  - Генерация структурированного отчёта `lotm_report.txt`
  - Автоматическое копирование краткой сводки в буфер обмена для мгновенной отправки разработчикам.
- 🗑️ **Чистое удаление в один клик**: полное удаление диагностического хука без повреждения файлов игры или модов.

---

## 📥 Как использовать

1. Скачайте **`LotmDiagnosticsTool.exe`** со страницы [Releases](https://github.com/kapgrek/lotm-ui-diagnostics/releases).
2. Запустите `LotmDiagnosticsTool.exe`. Программа автоматически найдёт установленную игру.
3. Нажмите **`📥 1. Установить диагностику в игру`**.
4. Запустите игру, откройте проблемные меню (магазины, инвентарь, карточки персонажей, диалоги) и выйдите из игры (или сверните её).
5. Нажмите **`🔍 2. Собрать отчет и проверить`**.
   - Программа проанализирует логи и виджеты.
   - Сформирует файл `lotm_report.txt` и откроет его в Блокноте.
   - Скопирует краткую сводку в буфер обмена.
6. Отправьте отчёт или сводку разработчикам.
7. После завершения диагностики нажмите **`🗑️ Удалить диагностику`**.

## 🛠️ Сборка из исходников

Для сборки требуется Windows и установленный .NET Framework 4.5+ (встроен в Windows 10/11):

```cmd
build.bat
```

Бинарный файл будет собран в `build\LotmDiagnosticsTool.exe`.
